## The Work

Four projects, four different problems. Here's the shape of each.

### 🎨 Pixora
**Problem:** AI image generation tools were either too complex for casual users or too limited for real use.
**Built:** A full SaaS platform — auth, usage limits, and a generation pipeline wired end-to-end.
**Stack:** `React` `Node.js` `Express` `MongoDB` `JWT`

### 🛰️ Anomaly Detection Framework
**Problem:** RPL-based IoT networks are vulnerable to routing attacks that traditional IDS miss.
**Built:** An ML framework that stays resilient even under adversarial network conditions.
**Stack:** `Python` `scikit-learn` `Pandas`

### 🧬 Brain Tumor Detection
**Problem:** Manual MRI classification is slow and inconsistent across radiologists.
